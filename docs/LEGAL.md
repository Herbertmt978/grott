# Licensing and Distribution Status

This fork preserves the upstream Grott Git history and does not add a repository-level license to inherited upstream code.

Upstream Grott currently does not include a license file that GitHub detects. Until the upstream maintainer clarifies the license, treat this fork as a beta distribution for testers rather than a broadly promoted redistribution. Do not relicense inherited files in this fork without explicit permission from the upstream maintainer.

The practical approach for this fork is:

- Keep upstream copyright, history, and attribution intact.
- Keep the public beta clearly marked as experimental.
- Publish Home Assistant and Docker images only as convenience images for people testing this fork.
- Ask upstream to add an explicit license, or get written permission before promoting the fork broadly.

Relevant upstream issue: https://github.com/johanmeijer/grott/issues/512
