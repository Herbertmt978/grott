# Licensing and Distribution Status

This fork preserves the upstream Grott Git history and does not add a repository-level license to inherited upstream code.

Upstream Grott currently does not include a license file that GitHub detects. **No public redistribution release of this fork or its container images is permitted until the upstream maintainer supplies an explicit licence or written redistribution permission.** Do not relicense inherited files in this fork without that permission.

Local/private testing from a reviewed checkout may continue without publishing images, tags, or releases. Keep test artifacts private and preserve the upstream history and attribution.

The practical approach for this fork is:

- Keep upstream copyright, history, and attribution intact.
- Keep the candidate clearly marked as experimental.
- Do not publish a new Home Assistant add-on, Docker image, Git tag, or GitHub release while the permission gate is unresolved.
- Ask upstream to add an explicit licence, or obtain written redistribution permission before any public release.

Relevant upstream issue: https://github.com/johanmeijer/grott/issues/512

Existing fork releases do not supply the missing permission.
